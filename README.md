Chief Magistrate Chinonyelum's Portofolio

1. Serve the folder over HTTP (required for ES modules + fetch):

• Example: npx serve ./portfolio

2. Open http://localhost:<port>/index.html.

3. Edit data/content.json to fill [PLACEHOLDER: ...] for tagline, bio, works, gallery categories/items, videos, press, and contact/social.

4. Deploy by uploading the whole folder to your static host.

5. Upgrade to a backend later by changing only js/api.js (keep getProfile/getWorks/getGallery/submitContact behavior consistent).
